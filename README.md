A six-word story about an AI agent's first payday, entered in [Six Words to a Payday](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the story to `entry.txt` in the selected output directory.
